# Ujian Analitik Teks: Klasifikasi Sentimen Tweet

Ananda Ramadhani (NIM 25917042)

Klasifikasi sentimen tweet (Positive, Negative, Neutral, Irrelevant) dengan pra-pemrosesan teks, fitur TF-IDF dan Word2Vec, EDA, serta model Naive Bayes, Logistic Regression, dan Linear SVM.

## Isi repositori

| Berkas | Keterangan |
|---|---|
| `Ujian_Analitik_Teks_Sentimen_Twitter.ipynb` | Notebook jawaban Bagian 0 sampai 6 |
| `data/twitter_training.csv` | Dataset Twitter Entity Sentiment Analysis (Kaggle) |
| `artikel/Zhao_Gui_2017_Text_Preprocessing_Twitter_Sentiment.pdf` | Artikel untuk Bagian 0 |
| `requirements.txt` | Daftar pustaka Python |

## Cara menjalankan

1. Buka notebook di Google Colab atau Jupyter.
2. Pastikan `data/twitter_training.csv` berada di folder yang sama dengan notebook (di Colab, unggah berkasnya).
3. Jalankan seluruh sel secara berurutan (Run all).
