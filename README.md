# UTS Analitik Teks

Ananda Ramadhani (NIM 25917042)

Klasifikasi sentimen tweet (Positive, Negative, Neutral, Irrelevant) dengan pra-pemrosesan teks, fitur TF-IDF dan Word2Vec, EDA, serta model Naive Bayes, Logistic Regression, dan Linear SVM.

## Isi repositori

| Berkas | Keterangan |
|---|---|
| `25917042_Ananda_Ramadhani_UTS_Analitik_Teks.ipynb` | Notebook jawaban Bagian 0 sampai 6 |
| `twitter_training.csv` | Dataset Twitter Entity Sentiment Analysis (Kaggle) |
| `Comparison_Research_on_Text_Pre-processing_Methods_on_Twitter_Sentiment_Analysis.pdf` | Artikel untuk Bagian 0 |

## Cara menjalankan

1. Buka notebook di Google Colab atau Jupyter.
2. Pastikan `twitter_training.csv` berada di folder yang sama dengan notebook (di Colab, unggah berkasnya).
3. Jalankan seluruh sel secara berurutan (Run all).
